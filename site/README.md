# Plumb public pages

These static files are the proposed public support and privacy pages. They have not been published. The content follows the drafts in [`../docs/release`](../docs/release). Keep both versions aligned with the exact app build.

Before publication, replace every `PUBLISHER_NAME_PENDING`, `SUPPORT_EMAIL_PENDING`, and `PUBLICATION_DATE_PENDING` marker with verified public details. Check the policy against the signed release build, then enable GitHub Pages with **GitHub Actions** as the source and run the manual **Publish Plumb support pages** workflow from `main`. The workflow rejects unresolved markers. Verify both public HTTPS URLs and add them to the app's Privacy screen and App Store Connect listing. Do not treat the source files in this public repository as the published policy URL.

The site uses system typography, semantic HTML, and one stylesheet. It has no scripts, analytics, forms, or third-party assets.
