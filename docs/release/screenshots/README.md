# Plumb App Store screenshot candidates

`iphone-18-pro-max-setup.jpg` is an uncomposited capture of the implemented setup screen from the iPhone 18 Pro Max simulator on iOS 27.0 (11 October 2026). It reflects the app source committed alongside this screenshot. The app was launched normally, without `-plumb-ui-demo`; the status bar was set to 9:41 with full signal and battery for presentation. The JPEG is 1320 × 2868 pixels, has no alpha channel, and has been visually checked at full size. Apple lists this as an accepted large Dynamic Island iPhone screenshot size in its [screenshot specifications](https://developer.apple.com/help/app-store-connect/reference/app-information/screenshot-specifications).

This is a **draft candidate**, not evidence of working physical-camera capture. Capture the result and comparison screens from the final implemented release candidate after the physical-device and specialist checks. Do not use the scripted UI demo input or the `-plumb-validation` timing readout in App Store screenshots.
