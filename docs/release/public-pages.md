# Plumb public pages

The static files in [`../../site`](../../site) are the proposed public support and privacy pages. The content follows the policy and support source in this directory. Keep both versions aligned with the exact app build.

The publisher, contact, and effective date are set to the details supplied by James on 11 October 2026. Check the policy against the final signed release build. GitHub Pages uses **GitHub Actions** as its source; run the manual **Publish Plumb support pages** workflow from `main` after content changes. The workflow rejects unresolved publication markers in the deployment files. Verify both public HTTPS URLs and add them to the app's Privacy screen and App Store Connect listing.

The site uses system typography, semantic HTML, and one stylesheet. It has no scripts, analytics, forms, or third-party assets.
