# Apple Human Interface Guidelines Agent Reference and Page Index

Apple’s Human Interface Guidelines describe how to design experiences that feel at home on Apple platforms. This reference gives agents a local, searchable map of the HIG’s 173 distinct linked pages and a concise set of design checks. It reflects the pages reachable from the [HIG home page](https://developer.apple.com/design/human-interface-guidelines) on 15 October 2026. Each entry links to its source; append `.md` to an Apple page URL when you need its official machine-readable Markdown.

The topic labels below are page outlines, not the full Apple guidance. For precise dimensions, platform behavior, API details, or recently changed advice, read the linked source.

## Fast design checks

- **Start with the person’s task.** Make primary actions and content easy to find, preserve agency, and keep the interface direct. [Design principles](https://developer.apple.com/design/human-interface-guidelines/design-principles)

- **Follow platform conventions.** Navigation, controls, windows, focus, and input should match each platform’s familiar patterns. See the platform pages under Getting started.

- **Design accessibly from the start.** Support text scaling, clear contrast, meaningful labels, alternative input, and appropriate motion. [Accessibility](https://developer.apple.com/design/human-interface-guidelines/accessibility)

- **Adapt the layout.** Preserve visual hierarchy across device sizes, orientation, multitasking, and safe areas. [Layout](https://developer.apple.com/design/human-interface-guidelines/layout)

- **Use visual systems deliberately.** Prefer semantic color, legible type, clear iconography, and materials that clarify hierarchy. [Color](https://developer.apple.com/design/human-interface-guidelines/color) · [Typography](https://developer.apple.com/design/human-interface-guidelines/typography)

- **Give feedback and recovery.** Show progress, explain outcomes, reserve interruptions for important decisions, and support undo when appropriate. [Feedback](https://developer.apple.com/design/human-interface-guidelines/feedback) · [Undo and redo](https://developer.apple.com/design/human-interface-guidelines/undo-and-redo)

- **Respect privacy.** Ask for access in context, explain its value, and collect only what the experience needs. [Privacy](https://developer.apple.com/design/human-interface-guidelines/privacy)

- **Choose native components by purpose.** Buttons act, tabs switch top-level destinations, sheets support focused tasks, and alerts demand immediate attention. See Components below.
