# Native UI Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Apply the researched native visual system across every existing app surface.

**Architecture:** Keep the shared workout model and data stores. Replace the home shell with native tabs and per-tab navigation; share semantic styling through HomeStyle. Update presentation components without changing measurement logic.

**Tech Stack:** SwiftUI, SF Symbols, XCTest, WidgetKit, watchOS.

**Spec:** [Native UI design](../specs/2026-10-15-native-ui-design.md)

## Global constraints

Preserve existing features and live edits in other worktrees. Use semantic system colours and fonts, minimum 44-point actions, light/dark adaptation and Reduce Motion. Do not add dependencies, notification permissions or fabricated metrics.

## Review focus

Empty history; returning to a selected tab after a set; largest Dynamic Type with keyboard; retake/error states; concurrent remote changes before publication.
